# MenuBar

MenuBar 可以折叠 macOS 菜单栏中不常用的图标。将图标拖到分界标记左侧即可收起，右侧的图标始终保留。操作使用系统原生拖动，无需辅助功能或屏幕录制权限。

## 安装

适用于搭载 Apple 芯片、运行 macOS 15 的 Mac。将 `MenuBar.app` 拖入“应用程序”并打开。也可以[从源码构建](AGENTS.md#构建)。

## 排列与折叠

1. MenuBar 启动时默认折叠。点击菜单栏中的箭头，展开后分界标记会变成双竖线。
2. 按住 **⌘ Command** 拖动菜单栏图标，把要收起的图标放在双竖线左侧，常用图标放在右侧。
3. 点击双竖线立即折叠，或等待 10 秒自动折叠。拖动图标或操作菜单时，自动折叠会延后到操作结束。

## 菜单栏选项

右键点击分界标记，或按住 Control 键点按，打开菜单。

- **登录时启动**让 MenuBar 在登录 Mac 时自动打开。若系统要求批准，会打开“登录项”设置。
- **紧凑间距**会缩小当前用户的菜单栏图标间距。切换时会短暂展开图标并重启控制中心，完成后恢复原来的展开或折叠状态。退出 MenuBar 后间距设置仍然有效。
- **退出**会移除分界标记，恢复图标显示。

## 故障排查

- **无法折叠**时，图标会保持展开。按住 ⌘ 调整分界标记的位置，再点击双竖线重试。部分系统图标无法移动，可见数量也受屏幕宽度和刘海影响。
- **间距未生效**时，可重新打开对应图标所属的应用，或重新登录 macOS。
